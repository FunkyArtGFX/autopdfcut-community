# Freigegebene Vorlagen

Hier erscheinen die von cz.design geprüften JSON-Vorlagen. Aktuell sind noch keine Community-Einreichungen veröffentlicht.

Datei herunterladen und in AutoPDFCut unter **Vorlagen → Importieren** übernehmen. Die Vorlage bleibt anschließend auf deinem Gerät und funktioniert offline mit passenden PDFs.
